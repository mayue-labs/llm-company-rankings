# 全球大模型公司排名概览

> 26 家全球大模型公司的单页排名概览：国家/地区、开源/闭源、代表性模型与桌面端产品。

在线访问：<https://mayue-labs.github.io/llm-company-rankings/>

## 项目概况

- 单文件静态页面，无构建、无外部依赖，直接用浏览器打开 `index.html` 即可。
- 数据截至 2026-11-17，综合排序而非单一榜单，参考 LMArena、Artificial Analysis、OpenRouter 调用量与桌面端生态。
- 顶部两张统计卡分别汇总国家分布与类型分布；表格固定表头，宽屏下填满剩余视口高度、内部滚动，尽量多显示行且不超出一屏。
- 口径、类型说明、地区说明与来源链接统一收在标题旁的 ⓘ 按钮中，以弹窗展示。
- 窄屏自适应：统计卡堆叠、表格横向滚动；打印时自动展开全部行与说明。

## 交互规则

用户视角：

- 点击标题行「非单一榜单」后的 ⓘ 图标，打开「口径与说明」弹窗；点击 ✕、按 Esc 或点击遮罩关闭。
- 表格区域可上下滚动，表头保持固定；窄屏可左右滚动查看完整列。
- 弹窗打开时锁定页面背景滚动。

实现视角：

- 原生 `<dialog>` + `showModal()`；`[data-close]` 按钮关闭；点击遮罩时通过 `getBoundingClientRect` 判断点击位置。
- `.table-scroll` 在宽屏下由 flex 撑满 `.table-card`；`thead th` 使用 `position: sticky; top: 0`。
- 无框架、无网络请求，所有数据写在 HTML 内。

## 修改注意事项

- 增删公司：编辑 `tbody` 行，同时更新 `meta-line` 的「共收录 N 家」、`.overview` 中的国家/类型计数与表格 `caption`。
- 国家/类型标签：沿用现有 class（`tag cn/ov/fr`、`tag open/closed/mixed`），颜色统一由 CSS 变量与标签规则控制。
- 调整可见行数：修改 `.table-card` / `.table-scroll` 的 flex 与 `@media (min-width:720px)`、`(max-height:780px)` 规则，不要写死高度。
- 说明文字与来源链接都在 `#infoDialog` 内，调整口径时同步更新 CHANGELOG。

## 维护与版本交付规则

每轮修改后：

1. 同步更新本文件「当前关键参数」与「版本记录」；
2. 在 `CHANGELOG.md` 顶部追加当日分组；
3. 核对统计卡、meta 行与表格行数一致；
4. 桌面与窄屏各检查一次，确认表格不超出一屏、弹窗可正常关闭；
5. 推送后等待 Pages 构建完成，再访问线上地址复核。
